# Моя утилита типа Nextcloud

 Эта утилита представляет собой простую систему хранения файлов и синхронизации, аналогичную Nextcloud, для Ubuntu Linux Server.

## Быстрая установка
Для автоматической установки используйте:
```
git clone https://github.com/pryanik-sdf/pryanik-cloud.git
cd pryanik-cloud
sudo bash install.sh
```
Установка включит всё, настроит systemd для автозапуска, и установит CLI утилиту `pryanikc`.

## Использование CLI
- `pryanikc -d` — показать подключенные диски
- `pryanikc -d <номер>` — выбрать диск и смонтировать раздел

## Основные функции
- Аутентификация пользователей
- Загрузка и скачивание файлов
- Простой веб-интерфейс для управления файлами
- API для подключения клиентов
- Хранение файлов на сервере

## Технологический стек
- Backend: Node.js с Express
- База данных: SQLite для пользовательских данных и метаданных файлов
- Frontend: HTML/CSS/JS (статический)
- Хранение: Локальная файловая система

## Развертывание на Ubuntu
1. Установите Node.js (если не установлено):
   ```
   sudo apt update
   sudo apt install nodejs npm
   ```

2. Клонируйте репозиторий (пример для GitHub):
   ```
   git clone https://github.com/yourusername/my-file-storage.git
   cd my-file-storage
   ```
   Или скачайте ZIP-архив с репозитория и распакуйте на Ubuntu сервер.

3. Установите зависимости:
   ```
   npm install
   ```

4. Запустите сервер:
   ```
   npm start
   ```

5. Откройте в браузере: `http://localhost:3000`

### Дополнительные настройки
- Для продакшена настройте переменные окружения (SECRET_KEY, PORT)
- Установите веб-сервер (nginx) для прокси
- Рассмотрите использование PM2 для управления процессами

### Безопасность
- Измените секретный ключ JWT
- В продакшене используйте HTTPS
- Ограничьте доступ к директории uploads

## Публикация кода
### Создание репозитория на GitHub
1. Зайдите на github.com и войдите в аккаунт.
2. Нажмите "New repository".
3. Назовите репозиторий: `my-file-storage`
4. Добавьте описание, например "Простая утилита хранения файлов типа Nextcloud".
5. Выберите Public (публичный).
6. Не отмечайте "Add a README file" (мы уже имеем).
7. Нажмите "Create repository".

### Загрузка кода
1. Откройте командную строку в директории проекта.
2. Инициализируйте git:
   ```
   git init
   git add .
   git commit -m "Initial commit"
   ```
3. Добавьте remote (замените yourusername на ваш логин):
   ```
   git remote add origin https://github.com/yourusername/my-file-storage.git
   git push -u origin master
   ```
4. Введите логин/пароль GitHub (или используйте токен).

Теперь код опубликован, и вы можете клонировать его на Ubuntu как описано выше в разделе "Развертывание".

## Настройка переменных окружения
Создай файл `.env` на основе `.env.example`:
```
cp .env.example .env
```
Настройки:
- HOST: IP адрес для слушания (например, 192.168.100.8 для доступа из локальной сети)
- PORT: Порт сервера (по умолчанию 3000)
- JWT_SECRET: Секретный ключ для JWT токенов (замени на случайный сильный ключ)

## Безопасность
- Helmet: Защита headers
- Rate limiting: Ограничение запросов (100 за 15 мин)
- HTTPS рекомендуем для продакшена

## Структура проекта
- server.js: Основной сервер
- public/: Статические файлы веб-интерфейса
- uploads/: Хранение загруженных файлов
- database.db: База данных SQLite
- .env: Файл переменных окружения
